## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 📜 **ফিকহ প্রথম পত্র (১২+ বিশদ প্রশ্ন ও ২৪টি পার্থক্য ছক)**:
  - কিতাবুল হজ্জ, কিতাবুন নিকাহ, কিতাবুত তালাক, কিতাবুজ জিহাদ, কিতাবুস সইদ, কিতাবুয যাবায়েহ এবং কিতাবুল উদহিয়্যাহ।
  - চার মাযহাবের ইমামগণের বিস্তারিত মতপার্থক্য, দলীল ও ফতোয়া বিশ্লেষণ।
- 📚 **বালাগাত ও মানতিক - ২১০ (১৯টি পূর্ণাঙ্গ প্রশ্ন)**:
  - **বালাগাত পর্ব (১০টি প্রশ্ন)**: ইলমুল বালাগাহ, ফাসাহাত, খবর ও ইনশা, আমর (১৮টি রূপক অর্থ), ইসতিফহাম (১২টি অর্থ), মুনাদা, তাকদীম (১২টি কারণ), ওছল ও ফছল, এত্নাব (৯ প্রকার), এবং ঈজায।
  - **মানতিক পর্ব (৯টি প্রশ্ন)**: তাসাওউর ও তাসদীক (হুকামা ও ইমাম রাযীর মতভেদ), দালালত (৬ প্রকার), মুফরাদ ও মুরাক্কাব, মানকুল, নাও, কাজিয়্যাহ, তানাকুদ (وحدات ثمانية), আকসে মুসতাবি এবং আকসে নাকীদ্ব।
  - মূল কিতাবের রেফারেন্স: *دروس البلاغة*, *المرقاة*, *شرح التهذيب*, *هداية النحو*।
- 🎴 **ডাবল-টিয়ার অ্যাকর্ডিয়ন (Two-Tier Accordion Collapsible)**:
  - প্রশ্নের হেডারে ক্লিক করলে সম্পূর্ণ প্রশ্ন উন্মুক্ত/বন্ধ হয়।
  - প্রশ্নের ভেতরের প্রতিটি সেকশন ব্লক (সংজ্ঞা, হুকুম, ছক, দলীল) স্বতন্ত্রভাবে Expand/Collapse করা যায়।
  - উপরে গ্লোবাল **"সবগুলো খুলুন / সবগুলো বন্ধ করুন"** টগল সুবিধা।
- 🏷️ **হরিজন্টাল পিল ট্যাব ফিল্টার (Horizontal Pill Tabs)**:
  - ভারী সাইডবারের পরিবর্তে উপরে মসৃণ ও আধুনিক মোবাইল-ফ্রেন্ডলি স্ক্রোলযোগ্য পিল ট্যাব বার।
- 🔍 **ইনস্ট্যান্ট সার্চ ও ফিল্টারিং**:
  - বাংলা ও আরবী উভয় ভাষায় তাৎক্ষণিক প্রশ্ন ও বিষয়বস্তু অনুসন্ধান।
- 🔖 **বুকমার্কিং সিস্টেম**:
  - গুরুত্বপূর্ণ প্রশ্নসমূহ ব্রাউজারে সেইভ করে পরবর্তীতে দ্রুত পড়ার সুবিধা (`localStorage`)।
- 🎯 **ইন্টারঅ্যাক্টিভ কুইজ টেস্ট**:
  - প্রতিটি বিষয়ের ওপর ব্যাখ্যাসহ এমসিকিউ কুইজ পরীক্ষা ও তাৎক্ষণিক ফলাফল।
- 🔠 **ফন্ট সাইজ কন্ট্রোল ও থিম সুইচ**:
  - সহজে বড়/ছোট ফন্টে পড়ার সুবিধা (`A+/A-`) এবং ডার্ক/লাইট মোড।
- 🖨️ **প্রিন্ট ভিউ (Print Ready)**:
  - পরীক্ষার আগে অফলাইনে পড়ার জন্য যেকোনো পেইজ সরাসরি প্রিন্ট বা PDF আকারে সেইভ করার সুবিধা।
- 📱 **১০০% রেসপনসিভ ও মোবাইল-ফ্রেন্ডলি**:
  - স্মার্টফোন, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসে সমানভাবে অপ্টিমাইজড।

## 💻 লোকাল সেটআপ ও রান করার নিয়ম (Local Development)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/asadullahshamimofficial/Elite-Preparation.git
cd Elite-Preparation
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:5173` অথবা টার্মিনালে প্রদর্শিত পোর্টে।

### ৪. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
```

## 🌐 ডেপ্লয়মেন্ট গাইড (Deployment Guide)

### Netlify Deployment:
এই প্রোজেক্টটি সরাসরি Netlify-এর জন্য অপ্টিমাইজড করা।
1. **GitHub** রিপোজিটরিটি Netlify-এ কানেক্ট করুন।
2. **Build Settings**:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
3. প্রোজেক্টে `public/_redirects` এবং `netlify.toml` ফাইল বিদ্যমান থাকায় যেকোনো রাউটে (যেমন: `/alim/fiqh-1st-paper` বা `/alim/balagat-and-mantiq`) রিফ্রেশ দিলেও **404 Page Not Found** ইরর আসবে না।
